1. Purpose

This Acceptable Use Policy ("AUP") sets forth the rules and guidelines for using AdOptimizer, a platform operated by 苏州杨芸电子商务有限公司 (Suzhou Yangyun E-Commerce Co., Ltd.). This policy is designed to ensure the security, integrity, and lawful use of our services, and to maintain compliance with Amazon's Selling Partner API (SP-API) and Amazon Ads API policies.

By using AdOptimizer, you agree to comply with this AUP. Violations may result in suspension or termination of your account and reporting to Amazon and/or relevant authorities.

2. Compliance with Amazon Policies

As an Amazon Public Solution Provider, AdOptimizer and all its users must strictly comply with:

  • Amazon Selling Partner API (SP-API) Terms and Conditions
  • Amazon Ads API Terms and Conditions
  • Amazon Acceptable Use Policy (AUP) — Sections 4.4 and 4.5
  • Amazon Data Protection Policy
  • Amazon Brand Analytics Role Requirements (if applicable)

Reference: Amazon's official developer documentation can be found at developer-docs.amazon.com/sp-api.

3. Prohibited Activities

The following activities are strictly prohibited when using AdOptimizer:

3.1 Unauthorized Data Access

  • Attempting to access Amazon seller data without proper OAuth authorization.
  • Sharing your AdOptimizer account credentials or Amazon API authorization with unauthorized third parties.
  • Using automated scripts, bots, or scrapers to access Amazon outside of official API endpoints.
  • Reverse engineering or attempting to bypass Amazon's API rate limits or security controls.

3.2 Misuse of Amazon Data

  • Using Amazon seller data obtained through AdOptimizer for purposes other than managing your own Amazon selling operations.
  • Selling, licensing, or transferring Amazon data to third parties.
  • Aggregating data from multiple sellers to create competitive intelligence products without explicit consent.
  • Using Amazon customer personal information (PII) for marketing, advertising, or any purpose other than fulfilling orders.

3.3 Prohibited Business Practices

  • Using AdOptimizer to manipulate product reviews, ratings, or search rankings.
  • Engaging in price-fixing, collusion, or anti-competitive behavior with other sellers.
  • Using the Platform to infringe intellectual property rights, including trademarks, copyrights, and patents.
  • Listing counterfeit, prohibited, or restricted products through automated tools.

3.4 Technical Abuse

  • Intentionally overloading, disrupting, or interfering with the AdOptimizer infrastructure.
  • Attempting to gain unauthorized access to other users' accounts or data.
  • Introducing malware, viruses, or other harmful code into the Platform.
  • Using the Platform to launch denial-of-service (DoS) attacks against any system.

3.5 Fraud and Deception

  • Providing false or misleading information during account registration or Amazon API authorization.
  • Impersonating another seller, brand, or individual.
  • Using the Platform to facilitate money laundering, tax evasion, or other financial crimes.

Zero Tolerance: Any use of AdOptimizer for fraudulent, illegal, or harmful activities will result in immediate account termination and may be reported to Amazon and law enforcement authorities.

4. Data Usage and Retention

AdOptimizer processes Amazon data in accordance with the following principles:

  • Minimal Access: We access only the data necessary to provide the specific features you have enabled.
  • Purpose Limitation: Amazon data is used solely to deliver services to the authorized Selling Partner.
  • Retention Limits: We retain your data only for as long as necessary to provide the Service or as required by law.
  • Secure Deletion: Upon account termination or your request, we delete your data within 30 days using secure deletion methods.

5. API Rate Limits and Fair Use

To ensure fair access for all users and compliance with Amazon's API policies:

  • Users must not attempt to exceed Amazon's published API rate limits.
  • AdOptimizer implements built-in throttling to prevent abuse. Users may not circumvent these controls.
  • Excessive or abusive API usage that negatively impacts other users or Amazon's systems is prohibited.
